@pack vocab

# C 1
Q: A named place in a program that holds a value is a:
A: Variable
W: Function
W: Loop
W: Comment
E: A variable is a label for a stored value, like a box with a name on it. Functions do work, loops repeat work.

Q: A reusable block of code that you call by name is a:
A: Function
W: Variable
W: Library
W: Constant
E: A function bundles steps so you can run them again by calling its name, often with inputs (arguments).

Q: Text in code that the computer ignores, written for humans, is a:
A: Comment
W: String
W: Variable
W: Syntax error
E: Comments explain intent to other people (and future you). In JavaScript they start with // and in Python with #.

Q: A piece of text data, like "hello", is called a:
A: String
W: Boolean
W: Integer
W: Array
E: Strings are text. They are usually wrapped in quotes so the computer knows they are data, not code.

Q: A value that can only be true or false is a:
A: Boolean
W: String
W: Float
W: Null
E: Booleans drive decisions: if something is true, do this; otherwise do that.

Q: An ordered list of values, like [3, 7, 9], is called an:
A: Array (a list)
W: Object
W: Loop
W: Index
E: JavaScript calls it an array; Python calls it a list. Items are kept in order and found by position.

Q: Code that repeats a set of steps is a:
A: Loop
W: Condition
W: Return
W: Bug
E: Loops (for, while) run the same steps many times, for example once per item in a list.

Q: A mistake in code that makes it behave wrongly is called a:
A: Bug
W: Patch
W: Feature
W: Build
E: A bug is any defect. Finding and fixing bugs is debugging.

# C 2
Q: The rules for how code must be written so the language can read it are its:
A: Syntax
W: Semantics
W: Runtime
W: Compiler
E: Syntax is grammar: brackets, colons, quotes. A syntax error means the code can't even be read.

Q: The values you pass into a function when you call it are:
A: Arguments
W: Returns
W: Variables in another file
W: Comments
E: Parameters are the names in the function definition; arguments are the actual values you pass in when calling it.

Q: What a function hands back to the code that called it is its:
A: Return value
W: Argument
W: Parameter
W: Callback
E: `return x` ends the function and gives x back to the caller.

Q: Where a variable can be seen and used in the code is called its:
A: Scope
W: Type
W: Index
W: Syntax
E: A variable made inside a function usually only exists inside that function. That boundary is its scope.

Q: The position number of an item in an array is its:
A: Index
W: Key
W: Length
W: Value
E: Most languages start counting at 0, so the first item is at index 0.

Q: A value that represents "nothing here on purpose" is:
A: null (None in Python)
W: 0
W: false
W: An empty string
E: null means intentionally empty. 0 and "" are real values; false is a Boolean.

Q: Grouped data stored as name–value pairs, like {name: "Tom", age: 40}, is an:
A: Object (a dictionary in Python)
W: Array
W: Loop
W: String
E: Objects store data by key (name) instead of by position. Python calls this a dict.

Q: A value that can't be changed after it's created is called:

# C 4
Q: A function that always gives the same output for the same input and changes nothing outside itself is:
A: A pure function
W: A recursive function
W: An async function
W: A global function
E: Pure functions are easy to test and reason about, because nothing hidden affects them.

Q: A function that calls itself to solve smaller pieces of a problem is:
A: Recursive
W: Pure
W: Asynchronous
W: Immutable
E: Recursion needs a base case to stop, or it runs until the call stack overflows.

Q: "Technical debt" means:
A: Shortcuts in code that make future changes slower and riskier
W: Money owed for software licenses
W: Bugs reported by users
W: Unpaid cloud hosting bills
E: Like financial debt, it charges interest: every future change costs more until you pay it down by cleaning up.

Q: Big-O notation, like O(n), describes:
A: How an algorithm's work grows as the input gets bigger
W: The exact runtime in seconds
W: How many lines of code a function has
W: How much a server costs
E: O(n) grows in step with input size; O(n²) grows much faster. It compares approaches, not exact timings.

Q: "Idempotent" means an operation:
A: Gives the same result whether you run it once or many times
W: Can never fail
W: Runs in parallel
W: Can't be undone
E: Setting a value to 5 is idempotent; adding 5 is not. It matters for retries in APIs and deployments.

Q: Code that is hard to change because everything depends on everything else is:
A: Tightly coupled
W: Loosely coupled
W: Highly cohesive
W: Well encapsulated
E: Loose coupling means parts talk through small, clear interfaces, so you can change one without breaking the others.

A: The requested resource was not found
W: The server crashed

W: The request worked
E: 2xx = success, 3xx = redirect, 4xx = client problem (404 not found, 401 unauthorized), 5xx = server problem.

Q: A status code in the 500s means:
A: Something failed on the server
W: The user typed the wrong URL

E: 5xx errors are the server's fault: a crash, a bug, or a dependency down.

Q: REST describes:
A: A style of API built around resources and standard HTTP methods
W: A database engine
W: A JavaScript framework
W: A way to put a server to sleep
E: In REST, GET /users lists users, POST /users creates one, and so on.

Q: CORS is:
A: A browser rule controlling which other websites a page's scripts may request data from
W: A CSS layout system
W: A type of database join
W: A compression format
E: Cross-Origin Resource Sharing. Servers send headers saying which origins are allowed. It's a common "why won't my fetch work" error.

Q: "Latency" is:
A: The delay before data starts arriving
W: How much data can flow per second
W: Server storage space
W: A security flaw

Q: A "webhook" is:
A: A URL one service calls to notify another when something happens

W: A database backup
E: Instead of you asking "anything new?" over and over, the other service calls you when there is.

Q: GraphQL differs from typical REST because:

Q: A "reverse proxy" like Nginx sits:

Q: TLS provides:

Q: A "read replica" is:

Q: "Denormalization" is done to:

E: It's a deliberate trade: faster reads, but you must keep the copies in sync.
